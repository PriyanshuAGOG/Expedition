# Nature ambience credits

`assets/audio/nature-ambience.mp3` is derived from the user-supplied forest
recording `soundreality-nature-forest-sound-537925.mp3`. It has been processed
for the website into a lightweight, seamlessly looping background bed:

- a clean 114-second section is extracted from the source recording,
- the tail is cross-faded over the head so the loop wraps without a seam,
- level is normalised to a gentle, consistent background loudness (~-22 LUFS), and
- it is encoded as mono MP3 at 96 kbps (≈1.4 MB, down from the original ≈9.7 MB).

The original 256 kbps stereo master remains in the project history if a
higher-fidelity source is ever needed. The raw component field recordings are
kept under `assets/audio/sources/`.
