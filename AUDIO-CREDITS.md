# Nature ambience credits

The site loops a lightweight field recording as the ambient bed. The primary source is `assets/audio/sources/gentle-breeze-birds.ogg` (~0.4 MB) — a real gentle-breeze-and-birdsong recording — chosen so the page does not have to download a large audio file before the experience can start. The audio element uses `preload="none"`, so nothing is fetched until playback actually begins on load or first interaction.

`assets/audio/himalayan-nature-ambience.mp3` (the user-supplied recording `soundreality-nature-forest-sound-537925.mp3`, included unchanged and renamed only for a stable asset path) is retained as an MP3 fallback for browsers without Ogg Vorbis support.
